# עבודה במקביל – איך מתחילים

כל סשן מקבל קובץ: `A.md` עד `E.md`. תכתבו לסשן: **"קרא את docs/sessions/X.md ופעל לפיו"**.

## צעדים ראשונים (בכל סשן)
1. לקרוא את `CLAUDE.md` ואת הקובץ של הסשן.
2. ליצור worktree וענף משלך מתוך התיקייה הראשית של הפרויקט. הפקודה המדויקת כתובה בקובץ של הסשן.
3. לעבור לתיקייה החדשה ולהריץ `npm install`. כל worktree צריך node_modules משלו.
4. לוודא שהכל עובד:
   - `npm test`
   - `npm run dev -- --port <פורט>` – כל סשן בפורט משלו, כתוב בקובץ שלו.
5. לעבוד **רק** בתיקיות שרשומות בקובץ שלך.

## תקשורת
- שאלות על החוזה (`src/core`) או בקשה לשנות אותו: לשלוח לסשן המתאם. מוצאים אותו עם ListAgents: הסשן שעובד בתיקייה הראשית `עורך PDF`. אם אין, לשאול את המשתמש.
- אם צריך משהו מסשן אחר, למשל פונקציה ב-`pdf-text.ts` של סשן A: לשלוח לו בקשה. לא לערוך את הקבצים שלו.

## סיום
1. לוודא ש-`npm run typecheck && npm run lint && npm test` עוברים.
2. לעשות commit בענף שלך, עם הודעה שמתארת מה נוסף, אילו תלויות חדשות נוספו ואילו שינויים נעשו ב-`src/core`, אם היו.
3. **לא למזג ל-main.** להודיע לסשן המתאם (או למשתמש) שהענף מוכן. המיזוג נעשה לפי הסדר A → D → C → B → E.

# עורך PDF

עורך PDF שרץ בדפדפן, ובהמשך גם כאפליקציית Android. הממשק בעברית ובאנגלית.

**האתר:** https://ymalka82810.github.io/PDF-Editor/

הקובץ נשמר כ-PDF אמיתי:
- הטקסט נשאר טקסט שאפשר לבחור ולחפש בו.
- האיכות נשמרת.
- הקבצים לא נשלחים לשום שרת.

## מה אפשר לעשות
- **עריכת טקסט קיים** (E): לוחצים על שורה ומשנים, מוחקים או מזיזים אותה. גם שורה שמערבבת עברית ואנגלית נפתחת כשורה אחת. הטקסט הישן נמחק מהקובץ, לא רק מוסתר.
- **הוספה:**
  - תיבת טקסט (T)
  - תמונה (I)
  - צורות: מלבן (B), אליפסה (O), קו (L) וחץ (A)
  - הדגשה (H) וקו חוצה (K)
  - ציור חופשי (P)
  - חתימה (S)
- **עמודים:** תמונות מוקטנות בפאנל צד. אפשר:
  - לשנות סדר בגרירה
  - לסובב, למחוק ולשכפל
  - להוסיף עמוד ריק
  - למזג קובץ נוסף
  - לחלץ עמודים או לפצל לקובץ לכל עמוד
- **טפסים:** מילוי שדות (גם בעברית), ושיטוח.
- **מסמך סרוק:** זיהוי טקסט (OCR, עברית ואנגלית), כדי שאפשר יהיה לערוך אותו או לחפש בו. הזיהוי צריך חיבור לאינטרנט בפעם הראשונה.
- **פתיחת תמונה** כקובץ PDF.
- **ממשק:**
  - מצב כהה
  - תצוגה מותאמת לטלפון
  - ביטול ושחזור
  - קיצורי מקשים (`?` מציג את כולם)
- **עבודה בלי אינטרנט:** אפשר להתקין את האתר כאפליקציה (PWA), והוא עובד גם בלי חיבור.

## הרצה
```
npm install
npm run dev
```

## בדיקות
```
npm test
npm run e2e
npm run e2e:offline
```
- `npm test` – בדיקות היחידה.
- `npm run e2e` – בדיקות הקצה לקצה בדפדפן.
- `npm run e2e:offline` – בודקת שהעורך עובד בלי אינטרנט, על גרסת ה-build.

כל push ל-`main` מריץ את הבדיקות ב-GitHub Actions ומפרסם את האתר.

## Android
שלד האפליקציה נמצא ב-`android/` (Capacitor).
- **מה צריך כדי לבנות:** JDK 17 ומעלה (עם `JAVA_HOME`) ו-Android SDK (עם `ANDROID_HOME`).
- **הפקודה:** `npx cap sync && cd android && ./gradlew assembleDebug`
- **עוד לא נבדק:** "פתח עם" (ACTION_VIEW) עוד לא מומש ולא נבדק על מכשיר.

## מבנה
| תיקייה | תפקיד |
|---|---|
| `src/core/` | מודל המסמך, קואורדינטות, רישום כלים, ייצוא עם pdf-lib, כתיבת טקסט עברי, תרגום |
| `src/ui/` | המעטפת: סרגלים, תצוגת העמודים, פתיחה ושמירה |
| `src/tools/` | הכלים. כל כלי בתיקייה משלו ונטען אוטומטית. דוגמה: `_example/` |
| `src/assets/fonts/` | גופן Alef (עברית ולטינית, רישיון OFL) |
| `tests/` | בדיקות יחידה, e2e, קבצי PDF לבדיקה (`fixtures/`) ועזרים |
| `docs/sessions/` | ההוראות לכל אחד מסשני הפיתוח שעובדים במקביל |

את הארכיטקטורה ואת כללי העבודה אפשר למצוא ב-`CLAUDE.md`.

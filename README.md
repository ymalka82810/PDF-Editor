# עורך PDF

עורך PDF שרץ בדפדפן, ובהמשך גם כאפליקציית Android. הממשק בעברית ובאנגלית.

הקובץ נשמר כ-PDF אמיתי:
- הטקסט נשאר טקסט שאפשר לבחור ולחפש בו.
- האיכות נשמרת.
- הקבצים לא נשלחים לשום שרת.

## הרצה
```
npm install
npm run dev
```
אחר כך לפתוח את http://localhost:5173.

## בדיקות
```
npm test
npm run e2e
```
בדיקות היחידה הן `npm test`, ובדיקות הקצה לקצה (e2e) הן `npm run e2e`.

## מבנה
| תיקייה | תפקיד |
|---|---|
| `src/core/` | מודל המסמך, קואורדינטות, רישום כלים, ייצוא עם pdf-lib, כתיבת טקסט עברי, תרגום |
| `src/ui/` | המעטפת: סרגלים, תצוגת העמודים, פתיחה ושמירה |
| `src/tools/` | הכלים. כל כלי בתיקייה משלו ונטען אוטומטית. דוגמה: `_example/` |
| `src/assets/fonts/` | גופן Alef (עברית ולטינית, רישיון OFL) |
| `tests/` | בדיקות יחידה, e2e, קבצי PDF לבדיקה (`fixtures/`) ועזרים |
| `docs/sessions/` | ההוראות לכל אחד מסשני הפיתוח שעובדים במקביל |
| `legacy/` | קוד מהפרויקט הקודם שעדיין מועבר ל-TS. התיקייה תימחק |

את הארכיטקטורה ואת כללי העבודה אפשר למצוא ב-`CLAUDE.md`.

## רישיונות
- pdf.js: Apache 2.0
- pdf-lib: MIT
- גופן Alef: SIL OFL 1.1 (`src/assets/fonts/OFL.txt`)
